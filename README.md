# ProcessKiller (基于 Shizuku 的底层强杀与安全防护引擎)

一款专为进阶用户打造的 Android 底层进程管理工具。突破系统限制，实现精准强杀、防锁机自保与环境集成。

核心特性
- **免Root强杀**：通过 Shizuku 注入 ADB 特权，底层强杀顽固后台进程。
- **防锁机**：支持“连按音量键”物理强杀，无惧恶意锁屏病毒。
- **环境内置**：内置 Linux 容器，支持 `apk add`、`python3` 及网络穿透。
- **静默安装**：集成静默安装器，方便管理 APK。
- **隐秘伪装**：包名为 `com.test.adblocker`，有效防止被流氓软件反制。

快速开始
1. 下载并安装 [Shizuku](https://shizuku.rikka.app/) 并激活。
2. 安装 ProcessKiller 并授予 Shizuku 权限。
3. 在设置中开启“音量键强杀”作为防锁机保险。
